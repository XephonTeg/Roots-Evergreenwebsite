# Root & Evergreen Internal Checklists

## 1. User Roles & Permissions Setup
- [ ] Assign roles to all users
- [ ] Set folder/doc permissions
- [ ] Review access quarterly

## 2. Notification Logic
- [ ] Identify notification triggers
- [ ] Set up calendar/email reminders
- [ ] Log all notifications sent
- [ ] Review notification log weekly
- [ ] Escalate missed actions

## 3. Continuity & Historical Tracking
- [ ] Create continuity file for each client
- [ ] Log all major decisions
- [ ] Version all policy documents
- [ ] Update handoff notes as needed
- [ ] Audit continuity files quarterly

## 4. Service Priority & Escalation
- [ ] Tag all requests/issues by priority
- [ ] Log escalations
- [ ] Review escalations in team meetings
- [ ] Escalate unresolved urgent items

## 5. Communication & Client Experience
- [ ] Document client preferences
- [ ] Use plain language in all comms
- [ ] Confirm receipt of critical updates
- [ ] Schedule regular check-ins
- [ ] Collect client feedback

## 6. Data Organization
- [ ] Set up standard folder structure
- [ ] Use templates for all docs/logs
- [ ] Maintain data map
- [ ] Onboard new team members to structure

## 7. Minimal Viable Tooling
- [ ] Shared folders/drives created
- [ ] Notion/Sheets for logs and tracking
- [ ] Email/calendar for notifications
- [ ] Templates in use for all workflows
